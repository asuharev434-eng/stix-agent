## Найдено и исправлено

- Проверка отсутствующих разрешений диктовки зависела от Info.plist тестового процесса и пропускалась. Теперь контроллер принимает Bundle с прежним значением по умолчанию .main, а тест использует отдельный bundle без ключей разрешений. Системный запрос и микрофон в этой проверке не запускаются.
- В схеме generate_image описание prompt было необязательным, хотя диффузия требует его. Компактная модель несколько раз отправляла пустой вызов. Поле теперь обязательное с явной инструкцией; для resize_only допускается пустая строка. Две новые регрессионные проверки прошли; до исправления проверка схемы воспроизводимо падала.
- После своей генерации приложение освобождало веса только если само запустило ComfyUI. При уже работающем локальном ComfyUI веса оставались загружены во время следующего ответа LLM. После завершённой диффузии теперь вызывается существующее освобождение памяти с проверкой пустой очереди; resize не выгружает модель. Цена — повторная загрузка весов перед следующей генерацией. При первом прогоне последний сценарий превысил 300 секунд на первой задаче; при повторе после изменений обе задачи завершились в пределах прежних таймаутов, общий процесс занял 418 секунд. Наблюдалась высокая нагрузка на swap; одно успешное повторение не доказывает отсутствие любых будущих задержек.

## Условия и границы проверки

Основная модель в capability-проверках — qwen3-8b-abliterated. Текстовые роли используют отдельные вызовы 8B; реальное переключение на qwen/qwen3.5-9b подтверждено анализом PNG с красным кругом. Создание файла в отдельном integration-тесте также использует 9B. Изображения — sd_xl_base_1.0.safetensors через 127.0.0.1:8188. Локальный API моделей — 127.0.0.1:1235.

Тестовые чаты и файлы изолированы от пользовательских. Терминал исполнял только заранее разрешённый printf STIX_TERMINAL_OK. Веб-проверка обращалась к DuckDuckGo и публичному swift.org. Деплой, GitHub и внешние сервисы инференса не использовались.

Основная 8B всё ещё может ошибаться в необязательных аргументах: в последнем повторе передала текст вместо пути mask. Исполнитель отклонил этот вызов, модель исправилась и завершила обе задачи. Это ограничение следования инструкциям модели, а не утверждение, что каждый вызов стал безошибочным. Проверки изображений подтверждают вызовы, PNG/новый файл и сохранение оригинала; качество произвольной ретуши не измеряют.

Сценарий проверки отсутствующих разрешений диктовки не проверяет качество распознавания речи. Приложения/браузер не входят в эти 12 тестов; предыдущая живая проверка установленного браузерного fallback описана в CAPABILITY-AUDIT.md.

## Воспроизведение

После swift test (сборка тестового бинарника):

```sh
python3 scripts/run-live-audit.py
# Повторить только проверки изображений после исправления:
python3 scripts/run-live-audit.py --start 11
```

Машинный отчёт: dist/remaining-tests/report.json; логи каждого запуска лежат рядом. Тесты требуют доступных локальных API, установленных моделей и разблокированного Mac. Обычный swift test намеренно не включает 11 opt-in live-тестов; их результат выше получен отдельным запуском с флагами окружения.
