# Проверка локальных возможностей · 18 октября 2026

Mac: Apple M4 Pro, 24 ГБ. Приложение 0.3.3, сборка 6. Только локальная установка и подпись Developer ID; без GitHub и деплоя.

| Возможность | Проверка |
| --- | --- |
| Генерация текста | Основная Qwen3 8B вызвала writing-специалиста; получен заголовок заметки |
| Генерация кода | Основная модель вызвала coding-специалиста; получена `def add(a, b): return a + b` |
| Генерация изображений | Выполнен generate_image через основную модель и отдельный /image через локальный SDXL; в UI проверены настоящие sampler-шаги 17/20 (85%) |
| Анализ текста и кода | reasoning-специалист нашёл IndexError при xs[0] для пустого списка и предложил проверку |
| Анализ изображений | Основная Qwen3 8B вызвала Qwen3.5 9B через delegate_model; специалист получил реальные пиксели и распознал красный круг на белом фоне. Основная модель осталась выбранной |
| Терминал | Основная модель вызвала run_shell: тестовый printf вернул ожидаемый маркер и Exit 0 |
| Приложения и браузер | Основная модель успешно открыла TextEdit через open_application. Инструменты snapshot, click/fill/scroll/key и Safari/Chrome подключены; пассивно подтверждены Accessibility, Screen Recording, Apple Events для Chrome. Остальная сквозная UI-проверка была остановлена, поэтому это не утверждение о проверке каждой операции |
| Редактирование изображений | Прямая проверка img2img и изменения размера ранее проходила. Основная Qwen3 8B также успешно вызвала img2img, но продолжила повторять вызовы, и полный тест завершился по таймауту. В 0.3.3 добавлены явные границы аргументов, конкретный путь готового файла в ответе и защита от повторного редактирования по тому же описанию внутри одной задачи. После изменения защиты полный live-тест ещё не повторён |
| Долгие задачи | Основная модель вызвала list_tasks/manage_task и поставила свою задачу на паузу; состояние пережило повторное чтение хранилища. Проверены очередь, редактирование, перестановка, корректировки, возобновление и скрытие карточек |

Текстовые роли в тесте использовали отдельные вызовы уже загруженной Qwen3 8B; реальное переключение на другую установленную модель проверено в vision-тесте. Специалист не получает инструменты и возвращает результат основной модели. Постоянные назначения задаёт пользователь через /models; автоматически изменять их агент не может.

Обязательных дополнительных моделей для этих возможностей нет. Qwen3.5 9B MLX 4-bit уже содержит vision-часть и прошла проверку реального изображения. SDXL поддерживает генерацию, img2img, маску и resize. Это не гарантирует точное исполнение любых сложных инструкций по ретуши.

Qwen3-Coder 30B занимает примерно 17.3 ГиБ только весами. На 24 ГБ она не назначается автоматически; допускается явный выбор пользователя в форме. Для обычных небольших задач предпочтительнее компактная 8–9B. Возможности браузера зависят также от разрешения JavaScript from Apple Events; наличие модели не заменяет системные разрешения.

Отчёты из отдельных тестовых чатов: dist/capability-web.json, dist/capability-text-code-terminal-tasks.json, dist/capability-pause-task.json, dist/capability-vision.json. Они содержат только синтетические проверочные задачи; пользовательские ключи и переписка в отчёт не копируются.

Для стабильной работы со многими инструментами используйте основную Qwen3.5 9B; аблитерированная Qwen3 8B в проверках иногда пропускала параметры и повторяла вызовы. Визуальный анализ 9B подтверждён отдельно. Выбор пользователя автоматически не меняется.

Интерфейс 0.3.3 проверен в установленном подписанном приложении: список `/` раскрывается вверх с зазором над полем ввода, прокручивается до последней команды, поле и отправка видны. Escape закрывает список, Tab подставляет `/image` без отправки и показывает два выбора моделей. Все 142 модульных теста прошли (11 отдельных live-проверок пропущены в обычном запуске).
