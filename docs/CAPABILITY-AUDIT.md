# Проверка локальных возможностей · 18 октября 2026

Mac: Apple M4 Pro, 24 ГБ. Приложение 0.3.3, сборка 6. Только локальная установка и подпись Developer ID; без GitHub и деплоя.

Текстовые роли в тесте использовали отдельные вызовы уже загруженной Qwen3 8B; реальное переключение на другую установленную модель проверено в vision-тесте. Специалист не получает инструменты и возвращает результат основной модели. Постоянные назначения задаёт пользователь через /models; автоматически изменять их агент не может.

Обязательных дополнительных моделей для этих возможностей нет. Qwen3.5 9B MLX 4-bit уже содержит vision-часть и прошла проверку реального изображения. SDXL поддерживает генерацию, img2img, маску и resize. Это не гарантирует точное исполнение любых сложных инструкций по ретуши.

Qwen3-Coder 30B занимает примерно 17.3 ГиБ только весами. На 24 ГБ она не назначается автоматически; допускается явный выбор пользователя в форме. Для обычных небольших задач предпочтительнее компактная 8–9B. Возможности браузера зависят также от разрешения JavaScript from Apple Events; наличие модели не заменяет системные разрешения.

Отчёты из отдельных тестовых чатов: dist/capability-web.json, dist/capability-text-code-terminal-tasks.json, dist/capability-pause-task.json, dist/capability-vision.json. Они содержат только синтетические проверочные задачи; пользовательские ключи и переписка в отчёт не копируются.

Для стабильной работы со многими инструментами используйте основную Qwen3.5 9B; аблитерированная Qwen3 8B в проверках иногда пропускала параметры и повторяла вызовы. Визуальный анализ 9B подтверждён отдельно. Выбор пользователя автоматически не меняется.

Интерфейс 0.3.3 проверен в установленном подписанном приложении: список `/` раскрывается вверх с зазором над полем ввода, прокручивается до последней команды, поле и отправка видны. Escape закрывает список, Tab подставляет `/image` без отправки и показывает два выбора моделей. Все 142 модульных теста прошли (11 отдельных live-проверок пропущены в обычном запуске).

## Обновление 0.4.0

Добавлены локальная библиотека скиллов и встроенный skill-creator, формы /skills и /memory, поиск /search с переходом к сообщению, диагностика /diagnostics, отдельные черновики чатов, локальная диктовка, редактор изображения с кистью/ластиком маски и сравнением, просмотр diff/до/после и отдельный durable-откат файла. Обобщённый журнал инструментов восстанавливает результаты из истории и блокирует неизвестные/повторные побочные эффекты. Контекст учитывает инструменты, системный промпт, ответ и реальный context length, когда native API доступен. LM Studio native API используется для выгрузки только моделей, первоначально загруженных STIX; предзагруженные пользователем модели не выгружаются.

До блокировки Mac полный набор: 178 тестов, 12 opt-in/permission тестов пропущены, 0 ошибок. Дополнительно проверен доступ к ресурсам скилла через FileTools при сохранении запрета на state.json и ссылки на него. Валидатор skill-creator подтвердил формат встроенного SKILL.md. Реальный локальный SSE-тест подтвердил остановку keepalive-потока без полезного прогресса.

В установленной подписанной версии 0.4.0 проверено наличие кнопки диктовки. В отдельной подписанной QA-копии с синтетическими данными открыта и прочитана инструкция skill-creator, показана форма памяти, открыт редактор изображения, нарисован штрих маски и включено сравнение до/после. UI diff с неверной тестовой целью внутри защищённого каталога данных корректно отказал; файловые diff/откаты вне каталога проверены модульно.

Mac заблокирован во время финальной проверки. Повтор полного набора с записью защищённых файлов после блокировки непригоден как результат: чтение StateStorage отказало из-за системной защиты данных. Новые live-проверки браузера, повторный сквозной main-model image edit и реальная диктовка пока не подтверждены. Микрофон не включался и частная речь не записывалась. Ограничение основного 8B-моделя из предыдущей проверки не считается автоматически устранённым только на основании новых guard-тестов.

Финальная release-сборка 0.4.0 и Developer ID подпись проверены. На диск установлена последняя сборка с ресурсами скиллов; установщик заменяет пакет через staging и сохраняет предыдущий пакет, не перезаписывая отображаемый в память исполняемый файл. Запущенный ранее процесс требует обычного перезапуска после разблокировки. Отдельный новый тест доступа к ресурсам скилла прошёл.
