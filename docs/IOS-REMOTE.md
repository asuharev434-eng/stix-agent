# Чат STIX Agent на iPhone

Приложение `iOS/STIXRemote.xcodeproj` показывает один чат с агентом на Mac. При первом запуске открывается сканер QR-кода. На Mac отправьте `/mobile` в любом чате и наведите камеру iPhone на код. Список устройств доступен через `/mobile devices`, отзыв всех подключений — через `/mobile revoke`.

Команды `/` отправляются тому же агенту на Mac. Чат iPhone хранится отдельно от обычных чатов, но использует установленные на Mac модели, инструменты, очередь задач и системные разрешения. Текстовая и графическая модели выбираются над полем ввода iPhone; при `/image` появляется отдельный выбор текстовой модели для подготовки промпта. iPhone показывает сообщения, результаты, изображения, прогресс и вопросы агента. Для работы Mac должен быть включён, приложение открыто, а модель доступна на Mac.

## Подключение из любой сети

Оба устройства должны быть авторизованы под **одним Apple Account** с включённым iCloud Drive/CloudKit. Когда устройства находятся рядом, приложение использует локальное соединение Bonjour/TCP. В других сетях оно передаёт зашифрованные запросы и ответы через **закрытую базу CloudKit** этого Apple Account. Отдельного сервера STIX и учётной записи STIX нет. QR-код передаёт случайный 256-битный ключ; после сопряжения ключ хранится в Keychain на обоих устройствах. CloudKit получает только AES-GCM шифротекст. QR-код действителен пять минут. Отозвать доступ можно командой `/mobile revoke` на Mac.

Для текущей реализации требуется один Apple Account на Mac и iPhone. Обмен между разными Apple Account, работа Mac в спящем режиме и push-уведомления не поддерживаются. Для длительной работы отключите сон Mac штатными настройками macOS. Локальный канал не требует iCloud и продолжает работать при отсутствии интернета.

## Сборка и подпись

1. Войдите в Apple Developer Account в Xcode → Settings → Accounts. Команда проекта `9TB7MZWNXU`; Xcode автоматически создаёт профили с CloudKit для `studio.stix.agent.remote` и `studio.stix.agent`.
2. Соберите iOS-приложение: `xcodebuild -project iOS/STIXRemote.xcodeproj -scheme STIXRemote -configuration Debug -destination 'generic/platform=iOS' -allowProvisioningUpdates build`.
3. Для Mac получите development-профиль: `./scripts/provision-mac-cloudkit.sh`. Затем укажите возвращённый путь в `STIX_MAC_PROFILE` и Apple Development identity команды в `STIX_SIGN_IDENTITY` при вызове `./scripts/build-app.sh --install`. Скрипт проверит App ID и разрешённый CloudKit-контейнер профиля перед подписью.
4. Откройте проект iOS в Xcode, выберите физический iPhone и запустите приложение. Для теста через интернет отключите Wi‑Fi на iPhone после сопряжения и отправьте короткую команду, например `/theme dark`. Проверьте появление ответа на обоих устройствах.

`STIX Agent.app` для публичного распространения требует отдельного **Developer ID provisioning profile** с CloudKit, подписи Developer ID, нотариального заверения и публикации схемы CloudKit в production environment. Development-профили и сертификат Apple Development предназначены для локальной установки и проверки; их нельзя выдавать за публичный релиз.

## Ограничения интерфейса

На iPhone доступны текстовые команды и выбор моделей, вопросы и подтверждения, защищённый ответ с ключом и просмотр изображений, созданных Mac. Рабочие папки, системные разрешения macOS и установка моделей управляются на Mac. Загрузка файлов и фото с iPhone в этот выпуск не входит. Некоторые сложные карточки Mac отображаются в мобильном чате как текст; соответствующие команды обрабатывает Mac.
