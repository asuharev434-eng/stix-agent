# Чат STIX Agent на iPhone

Приложение `iOS/STIXRemote.xcodeproj` предлагает явный выбор **iPhone / MacBook** над чатом. Режим iPhone запускает встроенную Qwen3 1.7B на телефоне без сети и без Mac; режим MacBook использует удалённый STIX Agent. При первом запуске можно сразу выбрать iPhone или подключить MacBook через QR-код: на Mac отправьте `/mobile` в любом чате и наведите камеру iPhone на код. Список устройств доступен через `/mobile devices`, отзыв всех подключений — через `/mobile revoke`.

В режиме iPhone доступны вопросы и генерация текста. Локальная история хранится только на телефоне, отдельно от чата MacBook. `/help` показывает локальные возможности; `/image` и другие команды Mac **не ставятся в очередь и не выполняются позднее**. Приложение оставляет такой запрос в поле ввода и предлагает выбрать MacBook. В режиме MacBook команды `/` отправляются агенту на Mac с его моделями, инструментами и системными разрешениями. Текстовая и графическая модели выбираются над полем ввода; при `/image` появляется отдельный выбор текстовой модели для подготовки промпта. iPhone показывает сообщения, результаты, изображения, прогресс и вопросы агента. Под каждой загруженной картинкой есть кнопка «Сохранить в Фото»; при первом сохранении iOS запросит разрешение на добавление фотографий. Для режима MacBook компьютер должен быть включён, приложение открыто, а модель доступна на Mac.

## Подключение из любой сети

Оба устройства должны быть авторизованы под **одним Apple Account** с включённым iCloud Drive/CloudKit. Когда устройства находятся рядом, приложение использует локальное соединение Bonjour/TCP. В других сетях оно передаёт зашифрованные запросы и ответы через **закрытую базу CloudKit** этого Apple Account. Отдельного сервера STIX и учётной записи STIX нет. QR-код передаёт случайный 256-битный ключ; после сопряжения ключ хранится в Keychain на обоих устройствах. CloudKit получает только AES-GCM шифротекст. QR-код действителен пять минут. Отозвать доступ можно командой `/mobile revoke` на Mac.

Для текущей реализации требуется один Apple Account на Mac и iPhone. Обмен между разными Apple Account, работа Mac в спящем режиме и push-уведомления не поддерживаются. Для длительной работы отключите сон Mac штатными настройками macOS. Локальный канал не требует iCloud и продолжает работать при отсутствии интернета.

## Сборка и подпись

1. Войдите в Apple Developer Account в Xcode → Settings → Accounts. Команда проекта `9TB7MZWNXU`; Xcode автоматически создаёт профили с CloudKit для `studio.stix.agent.remote` и `studio.stix.agent`.
2. Подготовьте встроенный движок и модель: `./scripts/prepare-ios-offline.sh`. Скрипт фиксирует версии и SHA-256, собирает iOS llama.cpp и добавляет Qwen3 1.7B Q4_K_M в приложение. Для сборки требуется около 1 ГБ места в готовом приложении; бинарники и веса не хранятся в Git.
3. Соберите iOS-приложение: `xcodebuild -project iOS/STIXRemote.xcodeproj -scheme STIXRemote -configuration Debug -destination 'generic/platform=iOS' -allowProvisioningUpdates build`.
4. Для Mac получите development-профиль: `./scripts/provision-mac-cloudkit.sh`. Затем укажите возвращённый путь в `STIX_MAC_PROFILE` и Apple Development identity команды в `STIX_SIGN_IDENTITY` при вызове `./scripts/build-app.sh --install`. Скрипт проверит App ID и разрешённый CloudKit-контейнер профиля перед подписью.
5. Откройте проект iOS в Xcode, выберите физический iPhone и запустите приложение. Для автономного теста выберите iPhone, включите авиарежим и отправьте текстовый вопрос. Для теста через интернет выберите MacBook, отключите Wi‑Fi после сопряжения и отправьте короткую команду, например `/theme dark`.

`STIX Agent.app` для публичного распространения требует отдельного **Developer ID provisioning profile** с CloudKit, подписи Developer ID, нотариального заверения и публикации схемы CloudKit в production environment. Development-профили и сертификат Apple Development предназначены для локальной установки и проверки; их нельзя выдавать за публичный релиз.

## Ограничения интерфейса

На iPhone в локальном режиме работает только текстовая модель. Генерация изображений, инструменты агента, рабочие папки, системные разрешения macOS и выбор моделей Mac доступны после выбора MacBook. Отправка файлов и фото с iPhone на Mac в этот выпуск не входит. Некоторые сложные карточки Mac отображаются в мобильном чате как текст; соответствующие команды обрабатывает Mac.
