# STIX Agent 0.8.2 — инструменты в ограниченном контексте

Если локальная модель загружена с небольшим context length, приложение больше не отправляет ей сразу все схемы инструментов. Перед каждым запросом выбирается набор, который оставляет место для системных правил, текущего сообщения, истории и ответа. Базовые файловые операции, терминал, проверка результата и `discover_tools` имеют приоритет. Поиск `discover_tools` открывает подходящие инструменты на следующем шаге; исполнение по-прежнему проходит исходную проверку аргументов и разрешений.

Список подбирается заново для каждого шага и учитывает тему запроса, в том числе русские названия типовых задач. Выбор основной модели в чате не меняется. Индикатор контекста показывает оценку с фактически предложенными инструментами. Если даже минимальный безопасный запрос не помещается в загруженное окно, приложение сохраняет историю и сообщает об этом.
