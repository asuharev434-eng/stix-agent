# STIX Agent 0.4: локальные инструменты и скиллы

Пользователь утвердил восемь предложенных направлений и добавил скиллы с предустановленным skill-creator. Сохраняем SwiftUI, локальные сервисы, существующие чаты, ключи и назначения моделей; без GitHub и серверного выпуска.

## Реализация

- Файлы: существующие backups/UndoRecord и durable-планы расширяются просмотром diff/до/после и откатом отдельной квитанции с проверкой конфликтов. Для batch-операций отдельные карточки файлов.
- Память: существующие записи preferences.memory доступны в редактируемой форме /memory. Поиск /search даёт фрагменты и переход к сообщению. Рабочие папки и договорённости сохраняются как явные записи пользователя.
- Контекст: ограничение с учётом модели, системы, схем инструментов и ответа. Старые сообщения сворачиваются в обозначенные дословные фрагменты; последние запросы и пары tool/result сохраняются. Полная история остаётся на диске.
- Выполнение: журнал инструментов восстанавливается из сохранённой истории; неизвестные результаты не воспроизводятся вслепую. Детектор повторов, монотонные таймауты стрима, безопасная выгрузка только загруженных приложением моделей через поддерживаемый native API.
- Картинки: sheet с маской, кистью/ластиком, силой, сравнением и списком вариантов. Исходники неизменны, маска локальная RGB PNG, запрос уходит в имеющуюся очередь.
- Голос: Speech/AVFoundation, requiresOnDeviceRecognition, без облачного fallback. По умолчанию ru-RU, язык меняется сообщением через voice_language. Результат в редактируемый черновик, без автоотправки.
- Диагностика: /diagnostics и инструмент run_diagnostics проверяют loopback API, список моделей/Comfy checkpoints/очереди, память Mac и разрешения. Проверки не загружают модели и не показывают новые TCC-запросы.
- Скиллы: папки Skills/<name>/SKILL.md с YAML name/description, references/scripts/assets по необходимости. Системе доступны метаданные, тело читается по необходимости через manage_skill. Явный вызов /skill/name или $name, управление /skills. Сохранение версий, проверка путей/размеров, отключение, импорт обычных папок и удаление в Корзину. skill-creator установлен из ресурсов и не перезаписывает пользовательскую версию.

## Проверка

Модульные проверки охватывают реальные файловые изменения/откаты/конфликты, пиксели маски, аргументы /image, формат скиллов и импорт, память/черновики после reload, контекст и журналы, таймаут реального локального SSE-потока, диагностику. Затем release build, подпись существующим Developer ID, сохранение state/app backup, установка и проверка в нативном интерфейсе. Живые GPU-тесты запускаются только при пустой пользовательской очереди. Диктовка проверяется без записи частной речи пользователя.

Затронуты Agent, Core, App, Tools, Integrations, Views, Resources/Skills, packaging plist/entitlements и Tests. Независимые подсистемы вынесены в отдельные файлы. Издержки поддержки: системные Speech/TCC и локальные API, без новой серверной инфраструктуры.
