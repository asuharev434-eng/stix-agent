# STIX-AI-0.1: собственная учебная модель

Файл: `stix-ai-0.1-f32.gguf`, архитектура GPT-2, 633 472 обученных параметра,
128 символов контекста, авторский русский корпус, случайная инициализация.
Исходники и веса: https://github.com/asuharev434-eng/stix-ai

Добавление выполняется обычным импортом GGUF. Файл копируется в `Models/`,
проверяется SHA-256 и сохраняется в manifest.json. Используется тот же
LocalModelLibrary / LlamaTextEngine / libSTIXLlama, что и для других GGUF.
Python, LM Studio и HTTP-сервер для запуска не нужны.

Для маленьких импортированных моделей с контекстом 128–256 включается
TinyTextPolicy: отправляется одно текущее сообщение, без системного промпта,
истории, вложений и инструментов. История чата сохраняется на диск.
Для STIX-AI-0.1 лимит вопроса — 94 символа, ответы ограничены оставшимся контекстом.
Такие модели исключены из автоматического назначения специалистов.

GGUF содержит `stix.chat_format=ru-char-v1`. Native bridge поддерживает этот
формат сериализации: BOS, «Вопрос: ...\nОтвет: ». Это формат входа нейросети,
а не шаблон ответа. Все символы ответа генерируются обученными весами.
Для других моделей по-прежнему используется llama_chat_apply_template.

Проверка настоящего файла и native bridge:

```sh
STIX_TINY_GGUF='/absolute/path/stix-ai-0.1-f32.gguf' \
STIX_TINY_BRIDGE='/absolute/path/libSTIXLlama.dylib' \
swift test --filter TinyRussianModelTests
```

Тест импортирует модель, повторно открывает библиотеку, загружает её встроенным
движком и проверяет настоящий русский ответ. Маленький синтетический корпус
сильно ограничивает качество; модель не предназначена для управления инструментами.
