# Контекстное окно и сжатие · 0.4.3

В строке ввода рядом с кнопкой добавления файлов появилось кольцо заполнения контекста. Нажатие открывает доступный размер окна, оценку токенов инструкций/инструментов/истории/изображений, резерв ответа и свободный остаток. Процент включает резерв ответа. При /image кольцо скрыто, поскольку этот режим использует отдельный короткий запрос подготовки промпта.

Размер загруженного окна берётся из локального native API. Для ещё не загруженной модели или несовместимого API используется консервативный предел до 32K, ограниченный известным максимумом модели. Оценка токенов приблизительная (UTF-8 с запасом, фиксированный резерв изображения), не результат токенизатора. Это указано в интерфейсе. Системные инструкции и схемы инструментов входят в расчёт. Резерв ответа передаётся серверу как max_tokens.

До очередного запроса при заполнении 75% запускается локальное сжатие. Его можно вызвать вручную кнопкой «Сжать сейчас», командой /compact или сообщением «Сожми контекст». На короткой истории кнопка отключена: последние четыре полные группы сообщений сохраняются целиком. Во время сжатия доступны остановка и очередь следующих сообщений; корректировка задачи появляется только для настоящей активной задачи.

Сжатие выполняет выбранная основная модель без инструментов и Thinking. Длинный исходный материал проходит ограниченными UTF-8 фрагментами; резюме обновляется последовательно. Промпт требует сохранить цель, ограничения, решения, пути/идентификаторы, подтверждённые действия, ошибки и оставшиеся шаги. В следующем запросе используется резюме плюс недавняя история. Текущий пользовательский запрос остаётся целиком, включая текущие пиксели для vision. Старые пиксели в резюме заменяются отметкой, а их исходная запись остаётся в полной истории.

Полная history и видимые messages не удаляются. Журнал побочных действий читает исходную history, поэтому сжатие не снимает защиту от повторного выполнения. Checkpoint содержит SHA-256 исходного префикса, число покрытых сообщений, модель, время и номер сжатия. Старые чаты читаются без миграции. При изменённом префиксе checkpoint игнорируется; после сбоя, отмены, смены модели или ошибки записи новое резюме не публикуется. Неудачное автосжатие не повторяется на каждом инструментальном шаге той же пользовательской задачи.

Если сжатие недоступно, остаётся защитный ограничитель запроса с дословными фрагментами старой истории и целыми парами инструментов. Он явно отмечает сокращённый вывод. Последний пользовательский запрос не обрезается молча: при невозможности передать его целиком приложение сообщает об этом. Резюме остаётся данными переписки, а не новыми системными разрешениями.
