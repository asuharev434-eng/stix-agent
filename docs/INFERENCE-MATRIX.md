Этот файл фиксирует **точные исходные артефакты** и отделяет известные свойства от ещё не измеренных. Ни один кандидат не становится базовой моделью только из-за размера. Окончательный выбор требует проверок из `Tests/STIXAgentTests/Fixtures/inference-quality.json` и выпуска с включёнными весами.

Тестовый Mac: Apple M4 Pro, 24 ГБ RAM. Минимальную поддерживаемую конфигурацию следует проверить отдельно. Замеры производятся при выключенных LM Studio и ComfyUI, без сетевых запросов, с одним активным движком за раз.

Размеры и SHA-256 текстовых файлов взяты из blob metadata Hugging Face для названных ревизий. Перед включением в сборку фактически скачанные файлы проверяются `shasum -a 256`. Размеры графических строк — сумма файлов весов четырёх обязательных компонентов; это **не** полный размер app bundle. Apple [описывает](https://github.com/apple-aiml-research/ml-stable-diffusion/blob/main/README.md) состав Core ML pipeline и необходимость VAEEncoder для img2img/inpainting.

## Протокол измерений

1. Для каждого текста: фиксированная температура/seed и одинаковые ограничения контекста; измерить первый токен, токенов/с, пик памяти, русский ответ, короткий код, структурированный вызов инструмента, отказ от выдуманного выполнения и отмену.
2. Для каждого графического комплекта: одинаковые prompt/seed/steps/размер; измерить время первой и повторной генерации, пик памяти, размер ресурсов, видимое качество, img2img и маску. Отмена должна останавливать вычисление и не создавать частичный результат.
3. Записать результат по каждому случаю в таблицу с версиями macOS, движка и файлов. Негативный результат сохранять, а не заменять оценкой «работает».
4. Условие допуска: текстовая модель выполняет проверяемый вызов инструмента с правильными аргументами и завершает простую файловую задачу без сервера; графическая модель создаёт и правит картинку offline; полные лицензии и notices проверены.

Мини-тест текста выполнен 19 октября 2026 на этом M4 Pro через нативный bridge `llama.cpp` `33d6135`/Metal, с контекстом 8192 и прогретым файловым кэшем. Это **не** полный агентный E2E и не замер холодной загрузки; отчёты получены `scripts/benchmark-llama.py`, не содержат пользовательских данных и лежат локально в `dist/reports/`. Они не доказывают пригодность модели для релиза.

Интеграционный тест подготовки `/image` на Qwen3 1.7B вернул валидный JSON, однако один прогон занял 922 с при сборке и загрузке ресурсов на этом Mac. Причина аномальной задержки не установлена; повторить замер перед публичным выпуском. Сравнение двух графических комплектов проводилось на одном Mac с одинаковой исходной картинкой и многоугольной маской. Оба дают сходную правку; качество сложной ретуши этим не доказано.
