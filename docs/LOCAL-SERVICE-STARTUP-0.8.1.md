# STIX Agent 0.8.1 — локальные сервисы при запуске

При открытии приложения STIX Agent одновременно проверяет настроенные локальные API LM Studio/Bionic и ComfyUI. Если API уже отвечает, приложение использует его без повторного запуска. Для LM Studio/Bionic сначала открывается установленное приложение, затем при необходимости вызывается установленная команда `lms server start --bind 127.0.0.1`. Приложение ждёт готовности API и выбирает доступный локальный адрес; если в настроенном API нет моделей, проверяет другие обнаруженные локальные адреса.

Для стандартного ComfyUI на `127.0.0.1:8188` или `localhost:8188` приложение сначала проверяет `/queue`, затем запускает установленный локальный ComfyUI без сети и пользовательских custom nodes. Если локальная установка недоступна, открывает Comfy Desktop. Ожидание готовности ограничено; при неудаче в интерфейсе появляется диагностическое сообщение. Для другого заданного адреса приложение не запускает сервер на неподходящем порту.

Запуск не меняет выбранные модели, чаты, ключи и память. ComfyUI, запущенный самим STIX Agent, останавливается при закрытии STIX Agent; ранее работавший сервер не останавливается.
